## 📸  2D LUT(64^3)기반 이미지 프로세싱 App



### Input 이미지 각 픽셀의 RGBA값을 통해 1차원 LUT.png파일로 변한된 LUT큐브를 인덱싱해 필터처리하는 필터앱입니다.

* 📝  제작 내용 : Input 이미지 각 픽셀의 RGBA값을 통해 1차원 LUT.png파일로 변한된 LUT큐브를 인덱싱, 기존 256^3에서 64^3으로 축소된 큐브를 보완하기 위해 이미지 선형보간(1D Linear Interpolation)적용.
* 🧑‍💻  개발자 : 진명인

   
* 기술스택 :
  * Android Studio
  * Aos
  * Kotlin
